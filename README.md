Project Goal
  This project solve a problem for job seeker where this app will give them all the job available in Linkedin and indeed to their city of choice 
  and also they can choose what kind of job they are looking for it will scrap all the job create a excel sheet and 
  it will send the report to their email which they can analayze

Tech stack Used
  this app is built in python which is build with help of claude with context engineering

     python3 setup_gmail.py
